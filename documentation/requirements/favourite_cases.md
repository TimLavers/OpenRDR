# Favourite cases
A Knowledge Base shall include a list of `favourite cases` selected by the user.

The currently selected case can be copied to the favourite cases list.
This is possible whether the current case is from the default case list, the cornerstone list,
or the favourite cases list itself.

The reason we only allow copying the current case to the favourites list is that there might be
more than one case with a given name, so in general there's no way for the user to specify
which case they want copied, unless it is the current one. As the favourites list should be
a carefully curated list, this requirement should not be a problem.

## Operations available on favourite cases
It shall be possible to:
- delete a case from the favourite cases list
- rename a case in the favourite cases list (to do)
- edit a case in the favourites list through the chat interface (to do). 

When a Knowledge Base is exported to a zip file, the favourite cases are
included.
